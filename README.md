# Tic Tac Toe Game

This is a simple Tic Tac Toe game I made using HTML, CSS, and JavaScript as a project to practice my web development skills.

## About the Game

The game is played by two players who take turns marking X and O on a 3×3 board. The first player to get three marks in a row, column, or diagonal wins. If all the boxes are filled and nobody wins, the game ends in a draw.

## Features

- Two-player game
- Shows whose turn it is
- Checks for a winner automatically
- Detects a draw
- Restart button to play again

## Technologies Used

- HTML
- CSS
- JavaScript

## Play the Game

You can play it here: https://ruthu2005.github.io/Tic-Tac-Toe-Game/

## Run on Your Computer

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
